# Shared scenario list for the shell harnesses.
#   id | shells (both = pwsh and zsh; zsh = zsh only) | pwsh counterpart | what it asserts
# tests/zsh/run.sh runs every line that lists zsh. It fails a line that is not
# a record, an id listed twice, a zsh line with no scenario_<id>, and a
# scenario_* function that no line lists (tests/zsh/index.sh). The pwsh counterpart column is one of
#   <File>.Tests: <Describe>[ / <It prefix>]   (required on a both line)
#   <name>.ps1: <what>                         (a pointer to the pwsh source)
#   n/a [why]
# tests/powershell/Parity.Tests.ps1 checks the same records and that every
# named test and file exists, here and in tests/zsh/scenarios-*.txt.
# Checks that both shells share (role gating, the local override, tool guards,
# the missing-tools hint) are rows of tests/parity.txt, not lines here.
