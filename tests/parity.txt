# Cross-shell parity list: ONE file, read by BOTH suites.
#   tests/powershell/Parity.Tests.ps1 (pwsh) and tests/zsh/scenarios-parity.sh (zsh)
# Each line is a check on a fresh sandboxed session; both shells must agree.
#   id|shells|role|tools|local|check|arg|expect
# shells : both | pwsh | zsh  (a line is skipped by shells not listed)
# role   : devbox | server | unset
# tools  : comma list of shimmed tools on PATH, - for none (empty PATH), or
#          core for a complete core install: every tool in shared/core-tools.txt
#          (and, on zsh, every pinned plugin)
# local  : the local override: - for no file, empty for an empty file, or
#          Name=value pairs joined by ; (each shell writes them in its own
#          syntax: Name='value' in local.zsh, $Name = 'value' in local.ps1)
# check  : cmd   arg=command name; expect present|absent (alias, function or command)
#          env   arg=variable name; expect its value
#          hint  arg=-; expect number of "run bootstrap" hint lines on startup
# Lines with the same role+tools+local share one session, so keep this list
# cheap. Every session must also start cleanly: exit 0, nothing on stderr.
#
